# Run a sweep

Set a cutoff for the current window and record the last completed cutoff. List eligible session notes before assigning any to readers. Compare fingerprints with the previous manifest so that a late edit to an older file can be examined. Save the old and new fingerprint with the reason it reentered the window. A restated observation gets no new count.

Partition the manifest so each path has a reader. Give readers the same definitions of direct observation, relay, and uncertainty. Ask for assigned and read totals, source locations, and any files they could not read. Reconcile the union of returned paths against the manifest. Matching totals alone could hide a duplicated path and a missed one.

Group evidence by failure, not by vocabulary. Record the input condition, what should have happened, and what was visible. For a missed instruction, distinguish a missing instruction from one that was available but overlooked. Leave the cause unknown if the note cannot settle it. A shared symptom alone does not establish a shared cause.

For each signal keep three counts: records considered for it, unique sessions that experienced it directly, and records that only relayed it. One session may write several records. A report that both cites a predecessor and describes a fresh run can support a direct observation if the fresh evidence stands alone. It is not also a relay-only record.

The owner chooses whether to request a repair, change guidance, observe another window, or close a signal with reasons. Prefer a narrow repair when normal inputs give a wrong result under a success status. Repeated documentation trouble may instead call for changing the instruction where the work is done. Record the next check, and keep resolved signals so an old alias does not open the same issue again.

In the example the first window has **3 records, 2 direct sessions, 1 relay**. The next check reruns both original input conditions and verifies use of the corrected output. Compare windows with their durations and eligible-file counts intact. Silence in a smaller window is weak evidence of a fix.
